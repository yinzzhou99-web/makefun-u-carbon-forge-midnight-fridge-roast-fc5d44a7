**Midnight Fridge Roast** — exactly one line, at most 200 characters, roasting a smart fridge that refuses to open after midnight. The fridge's petty rule is the target: "Midnight, and my smart fridge locks its door like a bouncer — it counted every snack I ate but never once counted a salad."

## Run it

```sh
python3 main.py
```

`main.py` (standard library only, no network) writes the roast to `/output/entry.txt` and checks it against the gate (1–200 chars).
